LONGFORM V9 — editable categories + quieter panes

What changed:
- Categories are no longer fixed to Important / Database / Misc.
- Use the small “manage” control beside category to add, rename, recolor, or remove categories.
- Saved-card category dropdowns and filter buttons update automatically.
- Removing a category safely moves its entries to another remaining category.
- Saved Thoughts and Write It Out can each collapse to a header-only state using the shared Personal Intranet collapse system.
- Fall 2 uses stronger category-tinted saved-note cards.

Storage:
- Entry data remains in pigeonhole-longform-v1.
- Category definitions use pigeonhole-longform-categories-v1.
- Both keys are covered by Safe Sync V2.
