PERSONAL ALMANAC V2 — archive + movable equal tiles

What changed:
- Almanac sections are now equal-sized tiles in a reorderable grid.
- Use the ⋮⋮ handle to drag tiles on desktop, or tap ⋮⋮ and then tap another tile to move it on touch/mobile.
- Tile order is stored in pigeonhole-almanac-panel-order-v1 and syncs through the existing Safe Sync rules.
- Collapsed tiles still shrink to header-only rows and the grid repacks around them.
- Meals, Quotes & Understandings, Dailies, Current Rotation, Restock, Wish List, and Strain Journal entries now have ↘ archive actions.
- Almanac archive actions use the shared pigeonhole-v10-archive history, so archived items appear on the Archive page with the rest of the Personal Intranet archive.
- No Supabase or CloudSync changes are required.
