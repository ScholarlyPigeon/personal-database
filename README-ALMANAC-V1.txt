PERSONAL ALMANAC V1

Purpose:
A practical, low-pressure reference room for repeating life knowledge rather than active project management.

Sections:
- Meals I Make — expandable rich-text meal cards
- Dailies — editable checkable recurring list + reset checks
- Quotes & Understandings — expandable rich-text cards
- Current Rotation — lightweight editable list for current favorites / go-tos
- Restock — editable checkable list + reset checks
- Wish List — editable checkable list
- Strain Journal — moved from Archive; existing entries are retained automatically

Storage:
- Main Almanac state: pigeonhole-almanac-v1
- Strain Journal remains: pigeonhole-v15-strain-journal
- Panel collapse state: pigeonhole-ui-panel-collapse-v1

All keys use the existing pigeonhole-* prefix and are covered by Safe Sync V2.
