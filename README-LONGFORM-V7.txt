LONGFORM V7 — mobile containment + real note titles

Upload only Longform.html to your existing GitHub Pages repo, replacing the current Longform.html.

What changed:
- Added a dedicated title field above the Longform writing area.
- Titles appear as real, editable headers on saved cards.
- Existing saved notes remain intact and show "Untitled note" until you title them.
- Titles are stored in pigeonhole-longform-titles-v1, so Safe Sync V2 syncs them automatically.
- Desktop image sizing is left alone.
- Mobile saved-note images are capped to a smaller centered natural-proportion preview with no cropping.
- Mobile Longform cards, text, rich-text content, and rails are constrained to the viewport so saved items cannot spill far off the right edge.
- The original V6 collapse/tools behavior remains untouched.

No changes are required to Script.js, Style.css, CloudSync.js, or Supabase.
